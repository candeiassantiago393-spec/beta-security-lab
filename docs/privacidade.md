# Privacidade

## O que fica no PC

- JPEG em `photos/` até exportar ou apagar.
- Cópias em `entrada-AAAA-MM-DD` no ambiente de trabalho após o arquivo diário.
- `config.json` (pode conter SSID e password Wi-Fi).

## O que **não** deve ir para o GitHub

Este repositório é **público**.

- Fotografias da entrada (`photos/`, já no `.gitignore`)
- Faturas, moradas, NIF
- `wifi_password`
- Dumps de série com dados pessoais

## Utilização

Destina-se ao **próprio** escritório / espaço. Cumprir a lei de videovigilância e aviso a quem entre, se aplicável.

## Rede

O servidor em `0.0.0.0:8080` é visível na LAN. Não abrir a porta no router. Não há autenticação na galeria nesta versão beta.
