Captura na entrada do escritório com LILYGO T-Camera S3 (PIR + câmara + OLED) e galeria no PC fixo via USB.

GitHub Pages só documenta o projeto. As fotos nunca passam por aqui: ficam no computador local.

Abrir interface local Código no GitHub

Como usar

  1. ESP32 ligado por USB à torre.
  2. No PC, na pasta do projeto: .\start.ps1
  3. O botão acima abre http://127.0.0.1:8080 neste computador.
